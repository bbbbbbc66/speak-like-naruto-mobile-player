## 1. 先说清楚「verified」到底验证了什么

这是本轮最重要的发现，比任何单个词都重要。

**所有证据都是「标题 / 页面文本 / 评论区原句级」，没有一条是逐字转写。** 原因很硬：

- B 站切片号基本不挂字幕轨，`yt-dlp` 全部返回无字幕，个别提示需登录
- 抖音视频 `yt-dlp` 报 403，需要登录 cookie
- 直播间聊天区在 iframe 里，弹幕原文抓不到，音频是静音的

所以词表里 `verified` 的准确含义是 **「出处可查」**，不是「逐字录音核实过」。这个定义必须写死，否则后面所有讨论都会跑偏。

### 证据分级

| 级别 | 含义 | 可信度 | 本轮数量 |
| --- | --- | --- | --- |
| A | 逐字转写（字幕 / ASR） | 最高 | **0 条** |
| B | 页面正文、评论区原句 | 高 | 少量 |
| C | 视频标题、推荐栏标题 | 中 | 大多数 |
| D | 镜像站 / 搜索引擎摘要 | 低 | 部分 |
| E | 文章二手转述主播内容 | 低 | 部分 |
| F | 精确搜索零命中 | 不收录 | 若干 |

**一句话**：这一轮把「出处可查」和「逐字核实」的界限划清楚了，但一条 A 级都没拿到。（第三轮换了采集方式，已补上 A 级证据，见 [`live-room-corpus.md`](live-room-corpus.md) 第 1 节；本报告的「本轮数量」仍指第二轮，两处口径不冲突。）

### 2.2 证据变弱，建议标注但不急着降级

| 词 | 现状 | 问题 |
| --- | --- | --- |
| **卡了** | `verified`、SKILL.md 核心梗 | 本轮**「卡了」二字原话未找到**。只找到「输了就是网卡」的标题逻辑（且是机翻英文标题，中文原标题待核）。口传确凿，但证据级别只有 D |
| **我了猪 / 刚 / 塞 / 雷** | `pending` | 不止「没找到」，还有**归属反证**：同帖把「我了个雷」归于 coke；「雷霆猪」合集是 VALORANT 内容，与本圈无关。这组词可能根本不属于看海 |
| **扫码** | `pending` | 新增两条原话（「金鸣就是扫码忍者」「这房子扫码了啊」），但仍**没有任何释义**，保持 pending |
| **雷刚饭 / 猪咪饭** | `pending` | 本轮零命中，维持 |

> 建议：在词表说明里给「卡了」加一句「证据为搜索摘要级，非逐字核实」。**不建议现在降级** —— 用户原始语料明确记录了它是看海的万能借口，且它在 SKILL.md 里承担「失误甩锅」这个功能位，删了会缺一块。

### 2.3 释义冲突，必须二核

| 词 | 冲突点 |
| --- | --- |
| **骨架** | 旧语料说「提这个关键词容易被封禁 / 被扣帽子」；新证据说它是「宇智波佐助·须佐能乎第一阶段骨架形态」，且为忍者外号。两个解释对不上，可能指的不是同一个东西，也可能「被封」的原因正是它牵涉某个有争议的佐助形态 |

保持 `pending`，等圈内人确认。**不要按新证据直接升级。**

## 5. 明确不收录

这份清单里有相当一部分内容不能进公开仓库，逐条记下来免得以后有人又捡回来：

- **个人身份信息**：真实姓名、性别、别称与真身的对应关系等，一律不收。本文件涉及若干条，全部排除
- **误记**：「手握日月摘星辰，世间无我这般人」全网只命中网络小说章节标题，与任何主播均无关联，上一版误记，已从 `language-system.md` 撤下
- **零命中原话**：「装菜」两句常引句、小豪两句锐评、「阳间代言人」、「这游戏环境又回到年初了」等，精确搜索均无出处
- **存疑别名**：某别名与 5G 是否为同一人，切片站把两者写成对战双方，未核实，不并入
- **纯评价性外号**：针对具体个人的评价词，按 `design.md` 第 4 节规矩排除
- **时效性组合梗**：主播两两联动产生的组合词，只在一个时间窗口内有效

## 7. 结论

1. **词表状态本轮一律不动。** 理由不是「没查到新词」，而是所有新证据最高只到 C 级，达不到「逐字核实」
2. **改动只发生在 `language-system.md`**：撤掉一处误记、标注两处证据不足、更新缺口表述
3. **要拿 A 级证据有三条路**：人工看片逐字听、上 ASR、**或捡站内已结构化的文本页**（抖音官方歌词页 / 视频页「AI 文稿」）。`yt-dlp` 这条路试过，B 站无字幕、抖音要 cookie，走不通；第三条路在第三轮跑通了，见 [`live-room-corpus.md`](live-room-corpus.md) 第 1 节
4. 本报告依据的原始清单**未归档进仓库** —— 它含个人身份信息和内部核对记录，公开前需要脱敏
