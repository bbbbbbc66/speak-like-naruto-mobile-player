# 火影手游直播间语言系统整理

> 对抖音 / B 站火影手游直播圈的语言现象做一次系统梳理：分几层、每个词什么来路、哪些可考、哪些还得再确认。
>
> 最后更新：2026-11-23 ｜ 词表本体见 [`../skills/speak-like-naruto-mobile-player/references/glossary.md`](../skills/speak-like-naruto-mobile-player/references/glossary.md)

## 0. 这份文档的定位

不是词表。词表只有「词 + 意思 + 例句」，这里要解决的是**结构问题**：这套语言为什么长这样、层与层之间怎么咬合、什么样的词能进 Skill、什么样的不能。

**置信度只有两档**，全文按这个标准标注：

- **已确认** —— 多个来源能对上，或有明确解释
- **待核** —— 只在弹幕、帖子里出现过，没找到明确解释。**不进 Skill，只进 pending**

## 1. 语料怎么来的（以及它的局限）

这次没有爬抖音评论区——登录墙挡着，`iframe` 里的弹幕原文抓不到，直播音频是静音的。实际做法是：

- 从 B 站、233 乐园、TapTap、虎牙、维基百科、游民星空、腾讯新闻等公开页面**拼**出来
- 抖音上做了浏览器实查，但只能确认**标题、点赞、热度、在线人数**，拿不到逐条弹幕

这带来两个必须承认的偏差：

1. **偏向「被写下来的词」**。评论区里那些说得最多、但从来没人解释的话，反而抓不到
2. **偏向「头部主播」**。小主播圈子里的说法基本是盲区

所以下文所有「已确认」，准确说是「有多源文字佐证」，不等于「我在直播间亲耳听过一百遍」。

## 2. 系统全景：四层结构

这套语言不是一锅杂烩，是四个功能层叠在一起的。混着看就会觉得毫无逻辑，拆开看每层都挺自洽。

| 层 | 功能 | 回答什么问题 | 典型词 |
| --- | --- | --- | --- |
| **L1 身份层** | 指认「谁是自己人、谁在装」 | 这人是什么货色？ | 串子 |
| **L2 情绪层** | 直播间的即时反应 | 现在什么气氛？ | 红温、破防、绷不住、吓哭了 |
| **L3 强度层** | 评价忍者与打法 | 这套东西强不强、正不正经？ | 阴间、阳间、穿三、偷分、绝活哥 |
| **L4 主播语系** | 单个主播的口头禅体系 | 这是谁的场子？ | 我了 X、词根串、神系语录、帝王系 |

**关键洞察**：L4 是**排他最深**的一层。L1-L3 圈内通用，跨主播都能听懂；L4 换一个直播间就失效，甚至同一个词在两个主播那里意思相反。

所以做 Skill 时，L1-L3 可以放心用，L4 必须标明归属。

## 3. L1 身份层：这个圈子只分两种人

### 3.1 一条被排除的破圈梗 —— 判定记录

> **0.4.1 判定注 / 0.4.2 补记（2026-11-23）**：用户核对指出该词**不是源于火影圈**，查证属实——它起于 2024 年 Alan Walker 模仿视频的标签误打，是全网破圈梗，火影圈是后来借用并中性化。0.4.1 已把它与派生说法从词表移除；**0.4.2 起，该词及其派生词形在本仓库任何文件中都不再出现**。本节只保留判定逻辑与来源，不收录词形，也不作为 Skill 的可用说法。

| 项 | 内容 |
| --- | --- |
| 意思 | 装腔作势、用力过猛，又菜又爱装，爱耍帅摆谱、立酷炫人设 |
| 起源 | 2024 年，一个中学生在晚自习模仿电音制作人 Alan Walker 虚空打碟，被同学拍下发到网上 |
| 关键细节 | 视频标签被误打成一个人名，这个男孩本人并不叫这个名字 |
| 扩散 | 抖音相关词条播放量超 **152.2 亿次** |
| 火影圈用法 | **不完全是贬义**，也可以指忍者帅、能秀操作 |

那个「标签误打」的细节很关键：**这个词从一开始就是个错误**。一个名字被安错了人，然后这个词自己活了下来。这类词天生带荒诞感，也正因为如此，**破圈 ≠ 圈内原生** —— 一个词在火影圈被用得多，不等于它从这里长出来。

**判定的连带结果**：它的派生说法（把「装」量化成数值、前缀叠加表极致、被冲击到的感叹）随主体一并排除；玩家自发的 0–5 分忍者评分表曾用它衡量「这个角色有没有表演空间」，属后期中性化用法，不作为收词依据。词表在 L1 身份层只剩「串子」，缺口见第 10 节。

**方法论**：往词表里收词，除了「有没有人用」，还要单独判「是不是这个圈子原生」。两条都过才收；只过第一条的，一律排除。这是 0.4.1 / 0.4.2 两次裁定留下的规矩。

### 3.2 串子 —— 唯一有词典定义的词

| 项 | 内容 |
| --- | --- |
| 意思 | 假装是某个群体成员 / 粉丝，说夸张、极端、挑衅的话，引战、带节奏、给对方招黑 |
| 维基百科定义 | 通过伪装成某一群体的支持者，发表夸张、极端或具有挑衅性的言论，以引发争议、损害该群体形象或制造群体对立 |
| 起源 | 电竞圈。A 队粉丝假装 B 队粉丝疯狂吹捧 B 队、拉踩别人，让路人对 B 队反感 |
| 旧写法 | 串杍 |

**火影圈的实际用法**：

- 「串两句飘带就吓哭了」—— 在直播间说两句带节奏的话，就被追着撕咬
- 「还敢不敢当串子了？」「还敢不敢带节奏了？」
- 主播自己也会串：「不开播的时候老喜欢在别人直播间里猛串」

**语义正在软化**：现在「串子」有时带调侃、甚至夸人会玩梗的意思，不是纯骂人。这一点很重要——如果 Skill 把「串子」当纯贬义词用，会和实际语感错位。

## 4. L2 情绪层：直播间的即时反应

这一层最实用，因为它们**语义稳定、跨主播通用、正常人也听得懂**。

| 词 | 意思 | 例句 |
| --- | --- | --- |
| 红温 | 急了、破防了，脸红上头 | 红温成火鸡了 |
| 破防 | 被说中了、绷不住了 | 又破防了？ |
| 绷不住 / 难绷 | 忍不住笑了 / 无语了 | 这波操作真的绷不住 |
| 吓哭了 | 夸张说法，效果太秀或太离谱 | 串两句就吓哭了 |
| 带节奏 | 故意挑起话题，引导弹幕往一个方向吵 | 别带节奏 |
| 建议加强 | 反讽。输了就喊加强 / 削弱 | 直接摆烂表示建议加强 |

**为什么这层最好用**：它们都在描述「情绪状态」，不涉及对人的判断。红温、破防、绷不住，说的是自己或场面的状态，不会踩到「评价具体的人」这条线。

**「建议加强」是纯反讽**。字面是「建议把某个忍者加强」，实际意思是「打不过，气得想骂策划」。用的时候不能真的当建议用，否则就成了正经反馈。

**直播间黑话里还有一批「场务词」**，不属于语言风格但必须认识，否则看不懂弹幕在说什么：

- **红色 SC / SC** —— B 站付费留言，红色的是大额
- **总督 / 舰长** —— B 站大额礼物与身份标识
- **动物园** —— 某一批熟人主播的圈子（待核，具体范围说法不一）

## 5. L3 强度层：决斗场的评价体系

火影手游是格斗游戏，所以「强度」是永恒话题。这一层的词密度最高，也最像行话。

| 词 | 意思 |
| --- | --- |
| 阴间 | 超标、恶心、机制离谱的忍者或打法 |
| 阳间 | 正常、讲道理的忍者或打法 |
| 穿三 | 一穿三，一个忍者打掉对面三个 |
| 反三 | 反手一穿三 |
| 撕咬 | 死缠烂打、近身纠缠的打法 |
| 偷分 | 用冷门或超标忍者偷偷上分 |
| 绝活哥 | 只玩一个冷门忍者，还玩得很绝的人 |
| 权威 | 顶级理解、说一不二 |
| 真投入 | 认真玩、真下功夫 |
| 信息差 | 对面不了解这个忍者 / 打法，靠信息不对称赢 |

### 5.1 「阴间 / 阳间」是一对，缺一不可

这是一组**相对词**。单说「阴间」只是骂，配上「阳间」才构成一套完整的评价坐标系：

- 阴间 = 机制不讲道理，赢了你也不服
- 阳间 = 打法堂堂正正，输了也认

圈内夸人最狠的一句其实是「你这把很阳间」——因为它承认了**你赢得干净**，比「断了」高一个段位。

### 5.2 「穿三 / 反三」是计量单位

不是形容词，是**战绩单位**。说「穿三」等于报了一个具体战果，比「厉害」精确得多。同理「反三」——被压着打然后翻盘，含金量高于普通穿三。

这种「用战绩代替形容词」的表达方式，是格斗游戏圈特有的语言习惯：**不评价，只报数**。

## 6. L4 主播语系：七个人，七套语言

这一层是整套系统里最「加密」的部分。同一个圈子里，主播之间的语言几乎不互通。

| 主播 | 语系 | 特征 | 代表表达 |
| --- | --- | --- | --- |
| 看海 | 锐评 + 嘴硬系 | 语气硬、话软；输了两把扣 72 分还能说「你赢了也不算」 | 「嘴硬的语气，最软的话」 |
| 鸽子神 | 神系中二语录 | 自封为王，术语全是「神」系 | 「我不知何为败北，因为我就是王神」 |
| 小豪 | 锐评 / 梯队系 | 点评式，爱给强度分梯队 | 「强度摸到 T0 顶梯队，上限拉满」 |
| 久安 | 帝王 / 家族系 | 直播标题高频用「殴打」「拷打」「出手」「拿捏」「从未跌落神坛」 | 「不是想赢，只是不想输」（出处未核实；第三轮查到的真实帝王系弹幕见 [`live-room-corpus.md`](live-room-corpus.md) 第 3.3 节） |
| 5G | 装菜系（待核） | 明明很强却自称装菜，但两句常引原话均无公开出处 | 「玩了七年新水」（账号名级） |
| 悟悟 | 环境抱怨系 | 吐槽环境、忍者强度 | 「这游戏环境又回到年初了，全是阴间撕咬忍者」 |
| 水姐 | 阳间系（称号待核） | 常被打上「阳间」标签，但「阳间代言人」这一称号未找到出处 | 「方了」（慌了，谐音） |

### 6.0 已纠正的两处误记

第二轮逐条核对后，上一版里的两处「代表表达」站不住，已撤：

- **「手握日月摘星辰，世间无我这般人」** —— 全网只命中网络小说章节标题，与久安的直播、切片、二创**没有任何关联**。疑似把小说原文误记成主播原话，不收。
- **「阳间代言人」** —— 「阴间 / 阳间」本身证据充分，但这个称号与水姐的绑定，精确搜索零命中，不收。

另有一处需要保持警惕：**「卡了」二字原话在第二轮里没找到**，只找到「输了怪网卡」的标题逻辑。它作为口传核心梗仍保留，但证据级别只是搜索摘要级 —— 这是**第二轮当时的判断**。0.4.0 的一手截图里出现五处原话，并补出「真卡 / 假卡」二分与「对话失误也能用」，详见 [`primary-corpus-analysis.md`](primary-corpus-analysis.md) 第 2.5 节。

### 6.1 看海语系：本仓库词表的主源

词表早期那 18 条里，一多半来自看海（0.4.0 当时全表升级为生成语法模型：55 条词条 + 6 条构式；0.4.1 后为 49 条词条，看海系占比已经降下来了）。他的语言特点是**用无意义音节当标点**：

- 我了 X / 我嘞 X —— **一条构式**，惊叹位置上的词根随便换（C1）
- 雷 / 刚 / 猪咪 当形容词 —— 无义词 + 名词（C6）
- 卡了 —— 万能借口
- 「雷霆」作为前缀，标记这套语系的归属（C4）

**历史记录（第二轮 → 0.3.2）**：2026-11-23 的抖音实查中，「我了猪 / 刚 / 塞 / 雷」这组原词一次都没出现，只见到近似句式；第三轮又在鸽子神《八连臭火》[官方歌词页](https://m.douyin.com/qishui/song/7674892857996789806)找到同形词串「我了刚蛋球爆塞雷」，于是四条全标 `pending`，归属反证一度被认为闭环。

**0.4.0 补记（这条被一手语料推翻了）**：用户提供的 9 张截图里，图 1「我了骚」、图 2「我嘞个钢蛋雷塞爆」「我了个不替」、图 3 教学评论「我了雷……雷、塞、猪、刚、爆、庭几个字都可以用，两两相组，不用在乎顺序，也没有固定搭配」（**作者赞过**）—— 逐字证据齐了。图 2 还明确标「全是海之言抽象词根」，与鸽子神歌词说**并列保留**，不单方面改写归属。

所以四条 `pending` 词条没有逐条升 `verified`，而是**合并成构式 C1**：它们本来就是同一条规则的不同实例。词根池也以图 2 的 15 个为准（霆 雷 塞 钢 爆 珠 蛋 骚 缸 猪 裂 球 阴 亏 替），替换 0.3.2 那组不全的旧清单。详见 [`primary-corpus-analysis.md`](primary-corpus-analysis.md) 与词表 `roots`。

**0.3.2 当时的记录**：可自由组合音节池是「刚、雷、猪、霆、塞、猪咪、刚蛋」叠「球、蛋、爆、压、纲 / 钢」，任意长度、任意顺序、全词性通用，只表程度夸张与身份识别。固定搭配不是独立词。当时按用户划的边界**只记文档、不改词表已有条目释义**；0.4.0 已把这条规则正式写进 `constructions`。规则与逐字实证见 [`live-room-corpus.md`](live-room-corpus.md) 第 3.5.1 节。

### 6.2 互相串的梗图谱

主播之间互相「串」是流量密码，也催生了一批组合词：

```
看海 × 小豪   →  撞车双声道
看海 × 鸽子   →  看海龙兜暴力穿三小鸽
鸽子 × 小豪   →  被小豪狙击了吗
水姐 × 鸽子 × 银色 →  水银鸽组合
5G × 久安     →  bo3
```

这些组合词**只在一个时间窗口内有效**，过了就废。不建议进词表。

## 7. 句法与音系：为什么「每个字都认识，连起来听不懂」

### 7.1 极短句

1 到 6 个字成句，超过 10 个字就开始出戏。

```
卡了。
断了。
别串了。
建议加强。
```

### 7.2 无主谓

主语谓语全省，因为说话人和听话人在同一个语境里。

| 正常说法 | 圈内说法 |
| --- | --- |
| 我这局网络卡了 | 卡了 |
| 这个操作很厉害 | 断了 |
| 这人明显在装 | 别串了 |

### 7.3 词性漂移

名词、动词、拟声词都能临时当形容词，判断标准只有「念着顺不顺」。

> 今天吃了个**雷**饭

「雷」不表示饭的任何属性。**它只表示说话人在这个圈里。**

### 7.4 空耳

把主播的连读、口音、语速听成另一组无关的字，一旦成立，原话就死了：

| 原话 | 空耳 | 结果 |
| --- | --- | --- |
| 「喜欢吗老弟」 | 「小猫老弟」 | 盖过原话，成为独立符号 |
| 佐助天照的日语台词 | 「阿玛忒拉斯」 | 全网二创 |

### 7.5 可抄的句式清单

这些句子是评论区原话，可以直接当 Skill 的语料：

- 「还敢不敢当串子了？」
- 「没绷住」
- 「这波操作太秀了」
- 「火影还是太权威了」
- 「建议加强」
- 「没绷住」
- 「你比主播还有理解？」—— 拿主播当权威压人

## 8. 语用规则：五个功能，三条边界

### 8.1 五个功能

| 功能 | 场景 | 表达 |
| --- | --- | --- |
| 认亲 | 确认对方是同圈人 | 任意圈内词试探，接住即成立 |
| 起哄 | 看别人操作 | 我了 X、断了、吓哭了 |
| 甩锅 | 自己失误 | 卡了 |
| 装弱 | 赢了之后降攻击性 | 卡了卡了、运气好 |
| 轻度嘲讽 | 有人装腔、带节奏 | 别串了、一眼串子 |

### 8.2 三条边界

**边界一：只评价事，不评价人。**

这类吐槽指向这次的说法，不指向这个人。一旦指向具体的人，就从玩梗变成人身评价。

**边界二：正事场合自动失效。**

这套语言信息密度太低，扛不住实际任务。

**边界三：密度必须低。**

三条回复最多一个梗。密度一高，就从「像圈里人」变成「在演圈里人」。

## 9. 置信度清单

## 10. 缺口与下一步

| 层 | 覆盖度 | 缺什么 |
| --- | --- | --- |
| L1 身份层 | 中 | 一条非火影圈原生的破圈梗 0.4.1 已移除（判定记录见 3.1 节），现只剩「串子」；圈内其他身份词基本空白 |
| L2 情绪层 | 中 | 高频情绪词收了 6 个，还缺大量程度副词和语气词 |
| L3 强度层 | 较高 | 忍者外号体系 0.3.2 已入库 10 条（台账归 L1，本表按功能放在评价层）；完整 17 条候选见 [`verification-report.md`](verification-report.md) 第 3 节，余下 7 条单源 / 歧义未收 |
| L4 主播语系 | 中 | 七位主播有标题级证据；第三轮补到 2 份 A 级逐字文本（鸽子神歌词、水姐口播），但覆盖面仍很窄 |
| 生成语法层（0.4.0 新增） | 较高 | 词根 15 个、构式 6 条、功能位 24 个已入库；缺的是跨主播的构式差异，以及 L2 词缀构式更多三档演进实例 |

**补齐有三条路**：

1. 拿到一手语料 —— 直播切片转写、弹幕抓取、社群聊天记录
2. **捡站内已结构化的文本页** —— 抖音官方歌词页、视频页「查看 AI 文稿」本身就是逐字文本，且能被搜索引擎索引。第三轮靠这条拿到了 A 级证据，但只对被做成歌曲或开了 AI 文稿的内容有效
3. 找圈内人做口述核对，把 `pending` 一条条转成 `verified`

没有第四条。凭空推导出来的「梗」，只会污染词表。

第二轮的 4 路并行核查结论在 [`verification-report.md`](verification-report.md)：它划清了「出处可查」和「逐字核实」的界限，但没拿到 A 级证据。第三轮补上了通道和两份 A 级文本，见 [`live-room-corpus.md`](live-room-corpus.md)。**两份报告的 A 级数量口径不同，是因为采集方式变了，不是互相矛盾。**

**0.4.0 补记**：第四条路其实是「用户直接给一手截图」——9 张抖音截图里有玩家自整理词根表、两张功能对照表、完整版串词和带「作者赞过」的教学评论，逐字文本一次齐了。这批材料直接把上面的四层结构掀了一层：它不是词库，是**生成语法**。词根、构式、功能表、语用约束已写入 `data/glossary.json`（schema 1.0），见 [`primary-corpus-analysis.md`](primary-corpus-analysis.md) 与 [`design.md`](design.md) 第 10 节。缺口从「没有 A 级证据」变成了「构式的跨主播差异还没核」。
