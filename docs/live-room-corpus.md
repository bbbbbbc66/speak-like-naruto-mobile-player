## 1. 采集方式与边界（先说做不到的）

**抖音站内直接抓，走不通。** 请求 `douyin.com/search/看海 火影` 返回的是 JS 空壳，正文为「搜索结果为空」，评论区和直播弹幕在 iframe / 登录后，未登录状态一律拿不到。上一轮台账里 `yt-dlp` 报 403、B 站无字幕的结论，本轮依然成立。

**但找到了第三条路。** 抖音有两类和视频绑定的站内页面会被搜索引擎索引，且页面里带的是逐字文本：

| 通道 | 拿到的东西 | 证据级别 |
| --- | --- | --- |
| `m.douyin.com/qishui/song/...` 官方歌词页 | 主播单曲完整歌词 | **A** |
| `m.douyin.com/shipin/...` 视频页的「查看 AI 文稿」 | 口播 ASR 转写全文 | **A** |
| `douyin.com/shipin/...` 视频页标题与描述 | 切片标题 | C |
| 公众号 / 频道里内嵌的抖音评论区截图（OCR 文本） | 评论区原句 | B |
| 自媒体文章里的引文 | 二手转述，未落到一手页面 | D / E |

**这一轮把 A 级从 0 条推到了有货。** 上一版台账说「要拿 A 级只有人工看片逐字听或上 ASR 两条路」，现在要改成三条 —— 第三种是「捡站内已被 ASR / 已结构化的文本页」，成本最低，但只对**被做成歌曲、或开了 AI 文稿**的内容有效，覆盖面窄。

沿用 [`verification-report.md`](verification-report.md) 的 A–F 分级：A 逐字转写 / B 页面正文与评论原句 / C 视频标题 / D 搜索摘要 / E 二手转述 / F 零命中。

## 2. 「串词」这个词有两种意思，都查了

用户说的「串词」在材料里对应两件不同的事，混在一起会污染词表：

1. **一串无意义音节** —— 主播把「雷、塞、刚、球、蛋、霆」这类字随机串联成句，不传递信息，只做身份识别。典型是看海雷霆语系、鸽子神八连臭火。
2. **串子刷的话术** —— 观众假装某群体成员，用复制粘贴的模板起哄、引战、互相指控「你是串子」。

前者是**主播语系（L4）**，后者是**社区行为（L1）**。下面分开记。

来源：[抖音汽水音乐](https://m.douyin.com/qishui/song/7674892857996789806)（A）、[Shazam 歌词](https://www.shazam.com/es-es/song/1836829060/e585abe8bf9ee381aee887ade781ab-e9b8bde5ad90e7a59e)（A）、[百度文库](https://set.baidu.com/view/6a25f0e16ddb6f1aff00bed5b9f3f90f77c64d5b.html)（B）。

**两条关键推论：**

- 歌词里出现了 **「我了刚蛋球爆塞雷」**。这解释了 `verification-report.md` 里那组悬案：词表里的「我了猪 / 刚 / 塞 / 雷」，以及待核清单里实查只见到近似句式「我勒自拍照 / 我了自拍」—— 后者对应歌词里的 **「校花自拍超听话」**。也就是说，这组词大概率是从**鸽子神的歌词**里拆出来或听岔的，**不是看海的**。上一轮的「归属反证」本轮得到 strengthening，维持 `pending` 是对的。
- 「压力爆大」「压力有点大」「老弟的 X 压」是同一套音节串的两种展开方式。做 Skill 时它属于 L4 且**强绑定鸽子神**，换直播间就不成立。

> 归属冲突，暂不判定：「我勒个骚刚」有梗百科说是鸽子神原声、因与 coke 声音相似被误认；另两处说是 coke 在 2023 年 10 月侠隐纲手期间由「我勒个豆」改编首创。**两说都没有一手音频**，按 F/D 处理，不写进词表。

### 4.1 决斗场评论话术模板（B 级）

[OurPlay 评论区](https://m.ourplay.net/comment/detail/653544) 有一整套按局势切换的模板，两条版本并列：

| 局势 | 说法 A | 说法 B（「老弟」体） |
| --- | --- | --- |
| 拿到先手 | 你有啥实力 | 你有啥实力，老弟 |
| 被拿先手 | 他这怎么敢来起手我的 | 不是，怎么敢的，老弟 |
| 连招失误 | **火影这破网什么时候修** | 不是吧，老弟 |
| 对面连招失误 | 连招都连不明白，小丑 | 不是，老弟 |
| 对面替身我通灵 | 都是思路 | 不是，老弟，你有啥实力 |
| 我替身对面通灵 | **一眼暗部** | 不是，老弟 |
| 输了 | 再战，祝你事事顺心 | 不是，老弟 |
| 赢了 | 就不点再战，哈哈 | 不是，诶~老弟 |

**「火影这破网什么时候修」是「卡了」的功能同义句**：同一个「失误甩锅给网络」的槽位，换了个说法。`verification-report.md` 说「卡了」二字原话没找到，本轮仍没找到原话，但拿到了**同功能位的两条独立旁证**（另一条见 4.3 论坛列举）。建议把「卡了」的证据级别从 D 上调到 C，仍维持 `verified` 不动 —— 它在 SKILL.md 里承担「失误甩锅」，删了会缺一块。

### 4.2 串子实录（B 级）

[腾讯频道「恋与火影」聚合帖](https://pd.qq.com/s/h6j1io48s) 记录了一个频道被串子占领的过程，标题即原句：

```
怎么全是串子，频道还有正常人吗
发 lian 的人都被我配了
你们这群真心恋的，其实都是串子     ← 评论区齐刷刷回「我是真心的」
串子都被我配了
你们这些小串子我来了
串子最爱用表情
配你们只是我的工作罢了
```

**机制比词条重要**：串子的核心动作是**互相指控对方是串子 + 无人承认 + 集体复读**。所谓「串词」不是固定词库，是一套可套用到任何话题的句式。做 Skill 时该学的是这个节奏，而不是背某句原文。

另有一例说明串子行为的边界风险：[搜狐游戏](https://game.sohu.com/a/1067412102_119620) 记某主播「骂完串，串完滑跪，跪完接着串」，跨圈后引发争议 —— 印证 SKILL.md「只起哄不惹事」这条规矩不是保守，是必要的。

## 8. 明确不收录

- **个人身份信息**：真实姓名、出生地、性别史、别称对应真身、抖音号、商务微信、QQ 号。水姐与 coke 的公开材料里成片出现，全部剔除
- **AI 生成的网络小说**：搜索里混进了《火影主播水姐：从音乐少年到顶流传奇的热血历程》一类站点（yypee / yitesi），文笔像考据、实为虚构连载。**它把「真得控制你了」写成了章节叙事**，差点被当成一手记录。凡此类站点一律不作为证据
- **攻击性 / 指向具体个人的评价**：论坛帖里对主播的贬损、输赢后的辱骂，不收
- **川祁语录**：只有公众号转述、无一手页面，E 级，不收
- **时效性组合梗**：双人联动产生的组合词，只在特定时间窗口有效
- **标题里对主播的称呼**：「小胖子」「暴猪形态」等是切片作者用词，不是主播语录

## 9. 仍然空白的地方

1. **悟悟**：四个目标主播里唯一零逐字语料的。查到的全是二手评价，没有一句他本人说的话。要么拿切片 AI 文稿，要么找圈内人核
2. **L4 归属字段**：本轮拿到的词几乎都带强归属（鸽子神 / 看海 / 水姐 / 久安 / coke），现词表的 7 个字段装不下这个维度
3. **真实评论区原文**：本轮 B 级材料来自「转载了抖音评论区的公众号」和「游戏社区评论区」，不是抖音评论区本身。抖音站内评论仍需登录态
4. **方言 / 谐音的准确字形**：「我了 / 我勒 / 我嘞」「刚 / 钢 / 纲 / 缸」「塞 / 赛」在各来源里混用，未做规范，收词前必须定一个标准写法

## 10. 结论

上一轮的结论是「A 级 0 条，只有两条路」。本轮改正为：**A 级可以从抖音站内已结构化的文本页（官方歌词、AI 文稿）直接取，但覆盖窄**。鸽子神《八连臭火》全本、水姐人物志口播是本轮最扎实的两份材料。

更重要的发现是那个**归属反证闭环了**：词表里被当作看海核心梗的「我了 X」组，在鸽子神歌词里找到了几乎同形的「我了刚蛋球爆塞雷」，以及对应「自拍照」的「校花自拍超听话」。上一轮把它整组降为 `pending`，现在看不是保守，是救回了一处误标。

**词表已按用户选择补入 5 条：45 条，verified 32 / pending 13。** 归属标注、未采纳清单与「不翻旧账」的边界见第 7 节。
