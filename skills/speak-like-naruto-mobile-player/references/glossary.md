# 梗词表（人读版）

当前版本 **0.3.1**，更新于 2026-11-23，共 **45 条**：verified **32** 条，pending **13** 条。

机器读版在 `data/glossary.json`，两边条数和内容必须完全一致，CI 会校验。

---

## 本版改了什么

### 0.3.1（第三轮语料）

补入 5 条**低争议**词条：压力、摸头村、黑暗组织、真得控制你了、我们普通人直接搂住。共同点是都有 A / B 级出处、释义明确、不含个人身份信息、不是攻击性内容。

强归属的三条（黑暗组织、真得控制你了 → 水姐；我们普通人直接搂住 → 久安）**没有新增 `owner` 字段**，而是把归属写进「来源」列，并在用法里标了「换场子慎用」。这样既不改 schema，也不把「这是谁的场子」这个维度抹掉。收词依据与未采纳清单见 [`../../../docs/live-room-corpus.md`](../../../docs/live-room-corpus.md) 第 7 节。

**没有采纳**：汗流浃背了吧老弟 / 阿玛忒拉斯（已破圈，超出直播间语系），忍者外号体系（「盾构」指向两个忍者，释义冲突未解），川祁语录（只有二手转述）。pending 13 条一个没动。

### 0.3.0（前两轮）

从 18 条扩到 40 条，主要补了 L2 情绪层和 L3 强度层（词的分层逻辑见 [`../../../docs/language-system.md`](../../../docs/language-system.md)）。

**一处降级**：「我了猪 / 我了刚 / 我了塞 / 我了雷」原本标 `verified`，全部降为 `pending`。原因是 2026-11-23 的抖音实查中，这四个原词一次都没出现；第三轮又在鸽子神《八连臭火》歌词里找到疑似真正源头「我了刚蛋球爆塞雷」。它们大概率真实存在，但**没有一手证据**，且很可能不属于看海。这正好是「不确定就标待核」的实战案例——自己写的规矩，自己先遵守。

## 怎么用这张表

- 做 AI Skill：读 `data/glossary.json`，只把 `verified` 的塞进上下文，`pending` 的不进
- **带归属的词**：「来源」列写了主播名的（黑暗组织、真得控制你了、我们普通人直接搂住），只在聊那位主播 / 那个场子时用，别当通用词到处塞
- 做查询、词库、机器人：直接吃 JSON
- 人肉参考：看这张表就行，别背，背了反而用得假

**最重要的一条**：这张表是词库，不是台词本。真正的说话风格靠 `SKILL.md` 里的密度控制——三条回复一个梗，比八个梗连发像人。

## 未收录的东西

以下内容**故意没有收录**，不是遗漏：

- **个人身份信息**：任何主播的真实姓名、性别、住址、家族叙事，一律不收
- **组合梗**：「撞车双声道」「水银鸽」这类主播联动词，只在一个时间窗口内有效，过期作废
- **纯脏话**：没有语义迁移价值的骂人话

理由都写在 [`../../../docs/language-system.md`](../../../docs/language-system.md) 里。
