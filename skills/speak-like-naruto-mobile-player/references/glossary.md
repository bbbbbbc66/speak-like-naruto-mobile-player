## 生成规则（先看这个）

```
L0  词根池    霆 雷 塞 钢 爆 珠 蛋 骚 缸 猪 裂 球 阴 亏 替
              （另：语气助词 塞/雷/钢/住 + 动作/动物 a/顶/猪/潘达）
       ↓  任意顺序、任意长度、两两相组、无固定搭配，只求顺口押韵
L1  自由串词  钢蛋雷塞球爆珠 / 雷塞钢霆 / 爆骚缸 / 大骚塞王
       ↓  加词缀、加动物/语气词，递归堆叠
L2  词缀构式  臭/骚 + 动词 → 臭a、骚顶、臭砍、骚通
               臭 + 动物/语气词 + 动词 → 臭猪a、臭塞雷猪a
               极限形态 → 雷霆暴力无敌大臭雷塞猪头肉a
```

**四条硬规则**：

1. 词根**可以任意组合**，不必背固定搭配。没见过的组合不代表错，只要顺口
2. 词串**本身不传递信息**，全靠音韵和语气。别试图给它编释义
3. 无意义形容词（雷 / 刚 / 猪咪）**没有实际含义**。「今天很雷」不是「今天很糟糕」，就是「今天很雷」
4. 词缀构式是**能产的**，别把「臭猪 a」「臭塞雷猪 a」逐个收成词条，那会无限膨胀

**C1 是合并点**：原词表四条 `pending`「我了猪 / 我了刚 / 我了塞 / 我了雷」不再各自立词条，四种说法连同新证据一起收进 C1 的实例。图 3 明说词根可换、顺序可换，所以「我了猪」和「我了塞」本来就是同一条规则的不同实例。

## 语用约束

**这套话为什么存在**（图 9 作者调侃，全批最值钱的一句）：

> 1v1 决斗场没法怪队友，玩家红温时只能把情绪宣泄给对面，久而久之催生出这套无厘头的押韵体系。

三件之前只能描述、不能解释的事，一起有答案了：

- 为什么全是攻击性很弱的无意义音节 —— 情绪必须有出口，但不能真骂人，攻击性被稀释进押韵里
- 为什么「卡了」是万能借口 —— 没有队友可甩锅，只能甩给网络这个谁都没法反驳的对象
- 为什么 `SKILL.md` 写「只起哄不惹事」是对的 —— 那不是保守，是这套语言内置的生存约束

**「卡了」是体面维护机制，不只是借口**：分真卡（服务器/网络客观问题）和假卡（无论网络状态如何，失误立刻一句「卡了」）；同时覆盖操作失误与对话失误两个域，承担甩锅、不服、狡辩、化解尴尬四个功能。说出它不需要真的网卡，既维持体面又显得低调有涵养。

**「断了」源自实力断档**：技术水平远超对手形成难以逾越的断档，所以既能夸人（你断了）又能自夸（我断了）。

## 状态说明

| 状态 | 含义 | 使用建议 |
| --- | --- | --- |
| verified | 有多个来源能对上，或有明确解释 / 一手逐字语料 | 可以放心用 |
| pending | 只在弹幕、帖子里出现过，没找到明确解释，或只有二手转述 | 少用。要用就贴在明显是玩梗的位置，别当实义词使 |

构式也带状态：C1–C5 有 A 类一手语料，`verified`；C6 只有词表旧词条抽象、具体词形无一手证据，`pending`。

## 怎么用这份表

- **做 AI Skill**：`SKILL.md` 里已写入构式规则与场景→说法的精简版。读 `data/glossary.json` 时，先读 `roots` + `constructions` + `functions`，`terms` 当索引用；只把 `verified` 的塞进上下文，`pending` 的不进
- **造词**：词根可以任意组合，不必查表。没见过的组合不代表错，顺口就行。但**三条回复最多一条带梗**，造得再对也别连发
- **带归属的词**：「来源」列写了主播名的（黑暗组织、真得控制你了、我们普通人直接搂住），只在聊那位主播 / 那个场子时用
- **外号类词条**：盾构、植物人、黄猿、红狗、普通人、塑料袋、虎皮、葫芦娃、黑色闪光、六道 X 是**专名映射**，只用于指代忍者，不参与玩梗密度计算。标了「单源」的三条（塑料袋、虎皮、葫芦娃）谨慎用
- **已破圈的词**：汗流浃背了吧老弟、阿玛忒拉斯圈外人也听得懂，用起来可以比 L4 词宽松一点
- **pending 的整句**：川祁语录那两句是 E 级二手转述，可以整句复用，但别当高频词、别拿它解释梗
- 做查询、词库、机器人：直接吃 JSON，注意 `schema` 是 `1.0`，五层结构
- 人肉参考：先看构式表和功能表，别背词表，背了反而用得假

**最重要的一条**：这份表是**语法，不是台词本**。真正的说话风格靠 `SKILL.md` 里的密度控制——三条回复一个梗，比八个梗连发像人。

## 未收录的东西

以下内容**故意没有收录**，不是遗漏：

- **个人身份信息**：任何主播的真实姓名、性别、住址、家族叙事、抖音号、商务联系方式，一律不收
- **组合梗**：「撞车双声道」「水银鸽」这类主播联动词，只在一个时间窗口内有效，过期作废
- **纯脏话**：没有语义迁移价值的骂人话
- **平台 AI 解析的释义作为一手出处**：页面自标「内容由 AI 生成，仅供参考」，可引用但必须标 B 类，不拿来给词条定含义
- **逐字组合出的无限词串**：`constructions` 收规则，不收「臭猪 a」「臭塞雷猪 a」这类无限实例
- **非火影圈原生的破圈梗及其派生词形**：0.4.1 判定移除，0.4.2 起全仓库不出现（判定记录见 `docs/language-system.md` 3.1 节）

理由都写在 [`../../../docs/language-system.md`](../../../docs/language-system.md) 与 [`../../../docs/primary-corpus-analysis.md`](../../../docs/primary-corpus-analysis.md) 里。
